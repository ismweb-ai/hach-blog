# AIエージェント導入前にベンダーへ聞くべき質問リスト

常駐型AIエージェントの導入を検討するとき、デモがうまくいったかどうかだけで判断すると、本番運用に入ってから想定外のつまずきに気づくことが多い。デモは短時間・限られたシナリオでしか動かさないため、セキュリティ要件や運用後の体制といった「地味だが決定的」な論点が後回しになりやすい。この記事では、稟議を通す前にベンダーへ確認しておくべき質問を、5つの観点に整理して紹介する。

## なぜデモの印象だけで決めると失敗するのか

複数の海外調査でも、AIエージェント選定の最大の失敗は「本番の業務フローで試さずに契約すること」だと指摘されている。デモは営業担当が最も見せたいシナリオを、最も条件のよい環境で動かしている。つまりデモの完成度は、実際の自社データ・自社の業務量での挙動を保証しない。

さらに、評価する側の心理的なクセも判断を狂わせる。デモの最後に強い印象を残す演出がされていると、全体の評価がその最後の印象に引き寄せられやすい([ピークエンド効果](/2026/10/peak-end-koka-shodan-mendan-owarikata-inshou-fuan/))。また「このベンダーは良さそう」「このベンダーは微妙」という最初の印象ができると、その後の質問への回答もその印象のフィルターを通して解釈してしまう([フレーミング効果](/2026/10/framing-koka-teian-tsutaekata-handan-bure-fuan/))。

これを防ぐ最も確実な方法は、**デモの前に質問リストを固定しておき、どのベンダーにも同じ基準で当てる**ことだ。質問を後から追加・変更すると、評価基準そのものが前の回答の良し悪しに引っ張られてブレてしまう([判断基準がブレる現象](/2026/10/gamblers-fallacy-saiyo-mensetsu-yoshin-shinsa-handan-kijun-burezuru-fuan/))。

## 確認すべき5つの観点

| 観点 | 確認すべき質問の例 |
|---|---|
| セキュリティ・データ | 推論時にデータはどこで処理されるか。機密情報のマスキングは自動か手動か。データは学習に使われないと契約で明記されるか |
| 連携・導入の軽さ | 既存のチャットツール(Slack/Teams/Chatwork等)にそのまま招待する形で使えるか。新しいツールへの入れ替えが必要か |
| 権限管理・運用体制 | 誰がどの範囲の指示を出せるか。誤った指示や想定外の動作を止める手段はあるか。停止・ロールバックの手順は明文化されているか |
| 料金・契約条件 | 料金プランは利用人数・利用範囲に応じて明確か。最低契約期間はどれくらいか。小さく始めて後から拡張できるか |
| 導入実績・サポート体制 | 同規模・同業種での本番運用事例はあるか(デモやPoC止まりでないか)。導入後の問い合わせ対応はどこが担うか |

この5観点のうち、特に見落とされやすいのが「権限管理・運用体制」だ。常駐型のAIエージェントは、人間が毎回指示を出さなくても自律的に動き続けるため、「何を・どこまで」自動でやらせるかの境界線を事前に決めておく必要がある。デモでは1タスクずつ動かすため、この境界線の問題は表面化しない。

たとえば「毎朝レポートを自動生成する」機能自体は多くのベンダーがデモで見せてくれるが、「レポートの元データに誤りがあったとき誰が気づくか」「エージェントが参照してよい情報の範囲は誰が決めるか」「想定外の挙動をした場合、誰の権限で止められるか」は、デモでは確認しづらい。こうした運用上の境界線を、契約前に文書として残しているかどうかが、本番運用後のトラブルの大きさを左右する。

## 質問リストはどう使うか

1. **全ベンダーに同じ質問を同じ順番で送る**。口頭説明だけでなく、文書での回答を求める(後で「言った言わない」にならないため)
2. **デモを見る前に質問リストへの回答をもらう**。印象が先に固まった後で質問すると、回答の評価がその印象に引き寄せられる
3. **PoC(小規模な試験導入)を契約の前提にする**。実際の自社データ・自社の業務量で数週間動かしてから本導入を判断する
4. **回答が曖昧な項目は宿題にして持ち越さない**。「後で確認します」が本番運用後まで解決しないケースは少なくない

## HACHの場合

HACH(ハッチ)は、Slack / Microsoft Teams / Chatwork / LINE WORKS に招待するだけで使い始められる常駐型AIスタッフだ。上記の質問リストに当てはめると:

- **セキュリティ**: 推論時に機密情報を自動マスキングし、データはAWS内で完結する
- **連携**: 既存のチャットツールに招待するだけで、ツールの入れ替えは不要
- **料金**: 月額98,000円〜(税別・1〜4名・3ヶ月〜)のスタータープランから、小さく始められる3プラン構成
- **運用**: 御社の判断基準に合わせて成長する設計で、一律のルールを押し付けない

もちろん、この記事の質問リストはHACHに限らずどのベンダーにも当てられるべきものだ。回答に自信を持てないベンダーがあれば、それ自体が重要な判断材料になる。

## まとめ

- デモの完成度と本番運用の安定性は別物。デモの印象だけで契約しない
- セキュリティ・連携・権限管理・料金・導入実績の5観点を、全ベンダー共通の質問リストとして事前に固定する
- 質問リストはデモを見る前に送り、回答は文書で残す。PoCを契約前提にする

AIエージェント選定の進め方そのものに不安があれば、無料相談で具体的な質問リストの作り方から一緒に整理できる。
